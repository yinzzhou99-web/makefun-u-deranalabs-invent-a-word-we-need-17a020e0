**Invent a Word We Need** — one invented word plus its one-line definition: *ghostdraft*, the long careful reply you type, delete, and replace with "ok".

## Entry

`main.py` (stdlib only) writes the word and definition to `/output/entry.txt`:

> ghostdraft (n.) — the long, careful reply you type, delete, and replace with “ok”.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
